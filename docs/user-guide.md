# 使用 SillyDraft

## 第一本小说

在书架新建作品，填写书名、简介、题材、文风、叙事视角和目标。打开作品后添加章节与场景，进入正文编辑器直接写作。也可打开内置“雾港来信”示例；示例只包含本地样本，不消耗模型额度。

正文自动保存；“保存并返回”或桌面 `Ctrl/Cmd+S` 立即保存。历史版本恢复形成新版本。不要把强制结束系统进程当成保存操作。

## 从角色卡和预设起步

书架 → 创作资源库 → 导入资源。选择类型后，查看导入预览和诊断。角色卡可使用 JSON、PNG 或 CHARX，其他资源使用 JSON。

角色卡详情 → 从角色卡新建小说。选择一个开场，填写故事中的用户身份；`{{user}}` 对应故事人物，不自动等于现实作者。未选择的备用开场不会成为已发生剧情。卡中明确的人物和世界资料带来源；示例对话仅供文风参考。

在作品创作助手的“角色卡与预设”中绑定具体资源版本。编辑生成新版本，已有作品不会被静默切换。现代聊天预设和提示词包提供条目开关、上下移动、内容/角色/注入深度/优先级与禁止覆盖编辑；其他字段仍能切换完整 JSON 编辑。未知字段保留。

生成前可查看实际提示词、资源版本、参数及兼容诊断。未支持的宏、模板 helper、世界书扩展或模型预填不能靠“成功导入”绕过；调整配置或选择能处理该参数的连接。正文生成不会自动带入全部编辑对话。

## 配置模型和生成正文

设置 → 添加模型连接。OpenAI 兼容端点通常填写以 `/v1` 结束的基础地址，模型 ID 按服务商提供的值填写；可以检查连接并获取模型列表。按需要为正文、编辑 Agent、资料整理和插画分别选择连接。密钥只进入系统安全存储。

编辑 Agent 适合理清人物动机、检索资料、委派写作或提出资料更新。它的回复不算正文。进入生成任务查看原始输出、错误或结果，再进入正文候选比较；采纳才更新作品。

选中正文片段后可局部改写，候选只替换选区。生成期间继续编辑导致依据版本过期时，直接采纳会被拒绝；保留当前稿，在新版本上重新生成或手动整理两份内容。

## 资料、地图与故事分支

资料库支持手工创建人物、设定、组织、物品、地点、事件、暗线和伏笔。区分事实、计划与推测，附上来源。AI 提取结果先进入审阅页；未采纳建议不会成为故事事实。修改来源正文后，相关资料会提示来源过期。

关系页创建有方向的关系，选择两端人物和类型；手机可选择关注人物查看附近关系。地图页选择或生成底图，再添加地点标记与路线。标记坐标按图片尺寸归一化，地图编辑保存后才能在别处使用。

分支页可以从选定场景分叉，也可以根据故事末尾生成多个走向或结局候选。选择候选后再继续写作；未选中的走向不进入事实。较早位置的分支不携带后来发生的设定、关系变化或宏变量。

## 插画和阅读

插画页填写描述，选择生图连接及参考资源；任务完成后保存到图库。可以设为封面、地图底图或在正文光标处插入。图片保留提示词、模型、来源版本与参考图信息。任务失败不会修改正文；重试会创建新任务，可能再次收费。

阅读器直接读取已保存正文与插画，可调整主题、字号和行距，使用目录、书签、搜索及阅读进度。删除 Agent 会话不会删掉小说。阅读器不显示模型原始推理、工具日志或未采纳候选。 标题、列表和引用保留编辑格式。若生成使用了 ST 显示正则，阅读器按当时的规则呈现；在“阅读设置”中可切换“显示原正文”。候选审阅也可关闭“预览显示效果”。这些显示变化不改写采纳及导出的正文。

## 备份、导出和同步

作品菜单导出 TXT、Markdown ZIP、EPUB，只包含选定分支的已采纳正文与所需图片。TXT 用文字标记图片；Markdown ZIP 解压后相对路径图片可一起迁移。

加密 `.sillydraft` 作品备份包含版本、分支、任务、资料、图片和原始 ST 资源，密码至少 12 个字符。密码不随备份保存，丢失后无法恢复。模型连接密钥不随作品备份迁移；新设备需要重新设置连接。

从书架恢复备份，先预览，再选择作为独立作品导入或在版本检查通过后替换。损坏文件、错误密码或不合法引用不会部分改写当前作品。

可选同步使用你控制的 HTTPS 文件端点，需要强 ETag、GET 与 `If-Match`/`If-None-Match` 条件 PUT。两台设备使用相同地址和备份密码。同步为手动整部作品快照传输；并发修改会保留冲突副本，再明确选择本地或远端版本。选择一侧仍会为另一侧保留副本；没有实时多人协同编辑。

## 任务中断与远程执行

直连任务在应用退出、网络断开后保留已有输出，不能恢复已经断掉的模型流。“重新生成（新任务）”会再次调用模型。

个人远程执行器可在手机断开后继续工作；重新打开任务页点击“获取远程结果”查询原 ID，不会补发一笔新请求。取消需得到服务端确认。部署与详细限制见 [远程执行器](../server/README.md)。

## 桌面快捷键

| 快捷键 | 操作 |
| --- | --- |
| `Ctrl/Cmd+S` | 保存正文 |
| `Ctrl/Cmd+N` | 新建作品 |
| `Ctrl/Cmd+O` | 打开创作资源库 |
| `Ctrl/Cmd+,` | 设置 |
| `Ctrl/Cmd+Shift+F` | 跨作品正文搜索 |
| 阅读器 `Ctrl/Cmd+F` | 当前分支搜索 |

宽屏工作区可拖动目录分隔线，也可聚焦后用方向键调整。macOS 使用原生菜单；Windows/Linux 使用应用内菜单。系统文字缩放与应用浅色/深色主题受支持，阅读器主题单独设置。
