# 远程作品库与扫码传输：手动验证

CI 无法覆盖相机与真实网络，发布前在真机上走一遍。

## 准备

- 一台 macOS / Windows 电脑（下称桌面）与一台 iOS 或 Android 手机，同一 Wi‑Fi；另测一次两边都在 Tailscale。
- 两边安装同一构建。

## 配对与使用

1. 桌面：设置 → 手机连接 → 打开。二维码出现，地址为局域网 IP。
2. 手机：书架 → SillyDraft ▾ → 扫码添加桌面。首次使用时系统询问相机与本地网络权限，允许后进入桌面作品库，标题显示“桌面：<名称>”。
3. 手机打开一章续写；生成开始后锁屏 1 分钟再解锁：任务在桌面上已完成或仍在进行，手机任务页显示一致。
4. 桌面与手机同时打开同一章，先在桌面保存，再在手机保存：手机提示版本冲突。
5. 手机导入一张图片作插图：桌面上立即可见。
6. 开启共享后，在桌面修改某个模型连接的地址并保存（手机端无法从界面改地址）：手机上用该连接生成仍然正常。

## 断线与恢复

7. 桌面关闭开关：手机顶部显示“桌面已停止共享”；点“切回本机”回到手机作品库。
8. 再次打开开关、手机重新切换；关闭桌面 Wi‑Fi 30 秒后恢复：手机提示断开后自动恢复，未保存的文字仍在。
9. 桌面“重新生成密钥”：手机切换时提示访问密钥无效并留在本机；重新扫码后配对列表只有一条。

## 扫码传输

10. 手机 → 桌面：分享一张角色卡，桌面粘贴链接接收，卡内图片可导入插图。
11. 桌面 → 手机：分享一个模型连接，手机扫码接收后可直接生成。
12. 同一二维码再扫一次：提示分享已失效。
