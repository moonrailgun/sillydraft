# 故事资料、分支与角色卡起步验证

2026-10-13，本机 Flutter 3.47.7 / Dart 3.13.5。测试使用内存或临时 SQLite、本地协议替身，没有调用付费模型。

资料以不可变版本记录，锚定故事章节；人物关系的逻辑 ID 跨分支保持一致，但查找始终限定分支和故事位置。历史分叉复制可见资料历史和变量快照。修改正文会使相应提取依据过期，作者需复核或重新整理。事实、创作计划和推测分别保存。

核心测试覆盖资料增删改查、来源和版本冲突、历史分支隔离、地图路线引用、AI 资料审阅、拒绝过期证据、候选选择幂等性，以及禁止分析结果引用输入快照以后的章节。编辑工具读取冻结的章节和资料快照；会话绑定编辑位置。资料建议通过独立审阅任务保存，生成或编辑对话不能直接写入正文或事实。

Flutter 流程测试覆盖：

- 手机创建并归档计划资料，正文不变。
- 地图路线保存和重开；删除地点移除失效路线；放弃未保存修改后正确返回。
- 选择一条候选创建新分支，原分支正文不变；分支比较与切换。
- 角色卡备用开场、主角名称映射、作品创建和旁路资料生成。

角色卡创建保留已选择开场的宏初始化，手动修改开场正文不会丢失这些变量。预览和创建共用宏时钟。世界书快照在资料页仅供查看；生成仍按绑定角色卡的触发规则执行。修改世界书需编辑资源并在写作配置中绑定新版本。

iPhone 17 / iOS 26.4 模拟器的原生构建与运行成功。实际界面操作创建计划资料，将资料绑定在第二章，再从第一章创建分支。工作区从 331 字、两章变为 197 字、一章；新分支不包含第二章的资料。截图记录了资料页和分支页，无溢出或遮挡主要操作。自动化输入工具只支持 US 键盘字符，截图中的测试文本由系统拼音键盘处理，不能作为模型输出示例。中文 IME 的独立验证见 [编辑器验证](editor-reader.md)。
