# SillyDraft 产品与交付要求

SillyDraft 是 Flutter 编写的小说创作与阅读应用，支持 Android、iOS、macOS、Windows 和 Linux。手机优先，桌面提供适合大屏的工作区。此文件将已讨论方案与“完整实现项目”的要求作为实现和验收依据。

用户已经授权自主实现和必要的设计决策；实现过程中直接解决常规选择，保留可审阅的代码、测试和进度记录。发布到商店、购买服务、使用用户未提供的密钥不属于本地实现任务。

1. 书架支持创建、编辑、搜索、归档和恢复小说，配置题材、简介、文风、视角及写作目标。
2. 小说按章节组织；正文使用可编辑的富文本结构，支持中文输入、撤销、自动保存、插画和不可变版本。恢复历史形成新版本。
3. 独立阅读器仅依赖正文及资产，支持目录、进度、主题、字号、行距、书签与搜索。Agent 会话删除不影响小说。
4. 编辑 Agent 与正文生成服务分开。对话、工具记录、任务和候选不混入正文；采纳才生成正文版本。旧提案不能覆盖并发修改。
5. 支持从 ST V1/V2/V3 的 JSON、PNG 和 CHARX 角色卡建立开头、人物与世界资料，支持备用开场、身份映射和未知字段保留。
6. ST 预设按 `st-preset-compatibility.md` 的格式和语义实现，包括聊天预设、提示词包、文本补全模板组合、宏、注入、世界书和文本正则。支持情况按实际行为标注；未支持扩展不可静默删除或冒充兼容。
7. 模型配置支持多个连接、写作/整理/生图角色、自定义地址、安全保存密钥、模型选择、流式响应、取消和明确错误。提供可离线体验的示例项目，示例内容不得冒充真实模型输出。
8. 旁路资料包含人物、世界设定、组织、物品、地点、事件、暗线和伏笔。支持手动 CRUD、搜索、来源、事实/计划/推测区分、AI 提取建议、冲突和过期分析。
9. 人物关系具有方向、类型及来源；手机显示局部图，桌面提供交互图。地图支持导入或生成底图、地点标记、路线与编辑。
10. 在当前故事末尾生成多个走向或结局候选，可选中续写、保存为分支和比较。未采纳候选不进入事实；各分支的人物状态、资料与宏变量隔离，查询受故事位置限制。
11. 生图服务支持人物和章节插画，保存提示词、模型、参考资源、状态、对应文稿版本；允许重试和插入正文，失败不影响写作。
12. 任务持久化输入快照、状态、工具步骤、流式部分结果、取消和错误。应用重启可恢复管理任务，不能假装断掉的模型流已恢复。
13. 本地优先：离线阅读和编辑，不强制账户。提供可选服务端执行长任务，手机可以断开后重新获取结果。服务端结果仍受基础版本检查。
14. 导出 TXT、Markdown、EPUB；项目备份包含版本、分支、资料和资产，可完整恢复。普通分享不包含密钥。提供可选多设备同步并显式处理并发冲突。
15. 手机支持触屏、系统文件导入/分享与安全区域。桌面支持导航侧栏、可调整工作区域、键盘操作、菜单、搜索和文件保存。提供浅色、深色及阅读主题，支持系统文字缩放。
16. 提供可复现的启动、测试和打包命令、平台工程、持续集成配置与用户文档。构建验证明确区分本机验证和待其他平台验证。

正文、资料及导出采用带版本号的数据格式。数据库提交使用事务；生成结果和候选采纳检查基础版本。删除优先可恢复；资产引用和导入路径必须校验，损坏备份不改变已有项目。

产品默认中文界面，保留可扩展的文案组织。界面提供空态、忙碌、错误、重试、未配置模型提示；没有真实实现的操作不得以无效按钮伪装。

完成证据需要覆盖：真实数据库重启、分支隔离与历史修改、真实样本导入、预设请求快照、网络协议错误与流式解析、任务中断、备份往返、移动/桌面界面流程、分析器及可用平台构建。外部模型费用由用户配置服务后产生，测试使用本地协议服务器验证调用，不消耗未授权服务。
