# 插图关联与重新生成

已批准范围：图片详情下展示参考图与所有关联成图的连线、缩略图和正文位置；参考图变化后标记“参考图不一致”；支持单张和全部重新生成。成功后替换当前分支中的正文图片，失败保留旧图，不删除历史图片。不提交或推送。

## 实现

1. 核心关联模型与版本替换
   - 使用资产元数据记录替代关系，无数据库迁移。
   - 汇总真实图片输入、视觉参考快照、当前资料和正文位置。
   - 任务完成事务内校验参考图、正文、资料版本；新资产成功后才替换正文及参考资料图片。
   - 冲突时保留新旧产物并说明未替换原因。
2. 重绘服务
   - 保存原始提示词，兼容已有最终提示词；复用参数和场景，解析最新参考图。
   - 顺序执行依赖项，失败停止，支持单独重试。
3. 界面
   - 详情页图片下显示连线关系、缩略图、状态、正文位置。
   - 单张重绘可修改提示词；批量统一确认数量、引擎与请求。
   - 显示进度、错误、取消和重新生成入口，手机可滚动。
4. 验证与规范
   - 核心测试覆盖参考图变化、共享依赖、顺序重绘、正文位置/历史/分支、失败/取消/并发冲突。
   - 界面测试覆盖宽窄布局、关系状态和重绘操作。
   - 运行分析、相关及完整测试、格式检查，检查实际渲染截图。

## 关联接口

- `StoryRepository.illustrationGraph(branchId)` → `IllustrationGraph`；供服务、完成事务和界面共用。
- `IllustrationService.regenerate(...)` → 持久化生成任务；`completeIllustrationTask` 统一提交替换结果。
- 图中节点均为当前分支下的有效版本，旧版本仍可从历史或图库查看。

## 审查重点

图片资产不可变；不改其他分支/历史正文；取消后不落图；正文或参考图并发修改不能被覆盖；不重复追加规范提示词；多个子图共用参考图时不重复生成；不调用付费服务测试。

## 实现结果与验证

- 全部重新生成只处理当前图片的关联后代，按依赖顺序去重；当前参考图本身使用单张重绘。旧图保留，成功才替换正文，失败不清空图片。
- 审查发现的两个问题已补回归用例并修复：显式选择的非默认参考图重绘后仍沿用该参考图；失败或取消后继续生成保留用户编辑过的画面描述。
- 核心完整测试 759 项通过，界面完整测试 363 项通过；包含本次新增的 16 项核心用例和 2 项界面流程用例。
- 界面用例覆盖单张、批量、失败后仅重试剩余图片、取消、提示词编辑、旧版本详情以及桌面悬停和键盘入口。
- 已查看 390 像素深色大字体（1.5 倍）、1200 像素浅色的关系图与确认弹窗渲染截图；宽屏关系图居中，窄屏保留横向滚动，节点和连线保留间距。截图使用测试字体与占位图片，已等待缩略图解码完成。
- `flutter analyze`、核心 `dart analyze`、仓库格式检查（347 个文件，0 个改动）及 `git diff --check` 均通过。
- 所有生图验证均使用本地模拟提供方。没有在原生运行中的应用重放历史，也没有调用付费生图服务。
