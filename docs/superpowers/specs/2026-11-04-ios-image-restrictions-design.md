# iOS 插画生成限制

用户已选择：iOS 版不提供色情内容生成入口，并补相应限制。这项变更针对已确认的 NSFW 插画路由。

采用运行时平台限制：iOS 设置不显示 NSFW 引擎，已保存的角色配置不生效但不删除；其他平台保留原行为。普通插画继续使用已有分类流程，NSFW 或无有效分类的请求不能进入生图调用。提示原因，不回退普通引擎。

仅隐藏入口不足以阻止旧任务和桌面代执行；因此限制进入任务快照并在执行时检查，重试、助手生成、参考图和重绘沿用。远程桌面必须声明支持此限制，否则 iOS 的生图任务明确要求升级桌面。iOS 不能批准桌面已有的 NSFW/未分类生图确认。

方案取舍：界面隐藏单独使用会漏掉旧任务；完全关闭 iOS 插画会损失普通功能；复用分类并增加执行限制是满足用户选择的最小完整方案。普通文字写作、ST 预设语义、已有作品和导入资源不在本次改动范围内。

限制：分类使用用户配置的文本模型，可能误判；本次不添加服务端内容审查或最终像素审核，也不承诺满足全部 App Review 要求。不得用“仅支持普通插画”描述冒充完善的审核系统。
