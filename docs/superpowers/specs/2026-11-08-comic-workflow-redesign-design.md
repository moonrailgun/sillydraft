# 漫画工作流与界面重设计

日期：2026-11-08
状态：待用户确认。用户要求“按你推荐的做法”，以下取舍均为设计者的决定，已在文末列出供核对。

本设计取代 `2026-11-08-native-comic-design.md` 中原创漫画的界面、关卡和“生成漫画 / 检查连续性”两个手动步骤。数据结构、任务恢复、版本冲突保护、资源归属、备份与远程，以及小说改编的忠实检查，仍按 `2026-11-07-comic-support-design.md` 与 `2026-11-08-native-comic-design.md` 执行。

## 现在的问题

来自用户截图与现有代码（`lib/features/comics/comic_screen.dart`、`comic_service.dart`、`comic_store.dart`）：

1. **漫画不在正文的位置。** 漫画作品在宽屏时中间仍是小说阅读器（`workspace_screen.dart` 的 `_page` 永远是 `ReaderScreen`），原创漫画章节正文为空，中间一片空白；漫画挤在右侧工具栏里。作者因此问“漫画怎么插入到正文”。
2. **关卡太多，且用内部术语。** “继续画”要求 `checked && complete && sourceCurrent`，`complete` 又要求每页没有 `visualReview`、指纹一致。任一不满足就禁用按钮，提示“先完成当前页，或在下方处理检查问题与未完成任务”，不说是哪一项。恢复历史会把所有图片标成待复核（`restoreComic`），任何编辑都清掉检查结果（`edit()` 置 `audit: null`），待复核还会顺着参考链传给后续页（`comicReferencesNeedReview`）。截图里第 1 页已画好，却同时卡在“分镜待检查”和“画面衔接待复核”。
3. **操作平铺。** 检查连续性、生成漫画、阅读、漫画 HTML ZIP、历史版本、重画此页、生图记录、确认画面衔接、编辑分镜同级排列，常用与罕用混在一起。
4. **实现细节外露。** “漫画任务 · 已完成 · 查看任务”卡片对作者没有意义。
5. **角色长相没有依据。** 原创页只靠上一页图片衔接；手动参考图藏在每格“参考图（0）”里，新作者不会用。

## 原则

- 漫画作品里，漫画就是正文：放在中间，读的地方就是画的地方。
- 原创漫画只有一个必经动作：**画下一页**。分镜、检查、提示词、参考图都在任务内部完成。
- 问题是提示，不是关卡。原创漫画只有两种情况不能继续，都在原地给出唯一的处理办法：本话有任务在跑；最后一页没有图（失败或取消）。
- 不常用的操作放进菜单。小说改编的忠实检查是改编的意义，保留为关卡。

## 从零开始画漫画

1. **新建**：书架新建作品选“漫画”（Beta 模式），填书名、题材、画风与视觉设定。与现在相同。
2. **开篇**：进入工作区，中间是开篇区。
   - 大输入框“第一页发生了什么？”，示例占位。
   - 一行画风（来自作品设置，可点“修改”打开作品信息）。
   - 开关“先画主要角色的定妆图”，默认开，说明“最多 3 张，之后每页都按它画”。
   - 模型状态一行：分析模型和生图模型的名称；缺连接时这一行变成“还没有生图模型 · 去设置”，配置后输入保留。
   - 主按钮“开始画”，下方一行“自动编排分镜、检查连贯，画成一整页。首次最多 4 张图。”
3. **绘制中**：开篇区原地变成第 1 页的占位，列出步骤与进度：编排分镜（n 格）→ 检查连贯 → 画角色定妆图（i/k）→ 画第 1 页。有“取消”。说明“离开也会继续”。角色出现在右栏资料里。
4. **读到新页**：画好的页出现在中间，从上往下像读漫画一样排列。最后一页下面是“接下来”区：
   - 三个方向卡片（标题 + 一句剧情），右上角“换一批”。点卡片把它的内容填进输入框并高亮，可再修改；**不会直接开画**。
   - 输入框“下一页发生什么？”，主按钮“画下一页”。
   - 次要按钮“本话完结，开始第 N 话”：新建一话并选中，输入框与三个方向带到新话的开头。
5. **循环**：每页的工具条有“重画”“改分镜”和“⋯”（生图记录、删除此页）。整话的历史版本在话标题旁的菜单和目录每话的菜单里。
6. **阅读与导出**：顶栏“阅读”进入全屏阅读；导出在“作品操作”菜单与目录中每话的菜单里，名为“导出漫画”。

“接下来”区只出现在最后一话的末尾。前面的话可以重画、改分镜，不在中间插入新页（见“不做”）。

## 角色定妆与自动参考

复用 `IllustrationService.planReferences` / `ensureReference`，不新建参考图机制。

- 原创规划（`original-plan`）的输出增加本页出场的主要人物：名字和外观要点。
- 开篇且开关开启时：对主要人物（最多 3 个）调用现有流程，已有资料条目和图片的直接用；没有的建角色资料条目，并按现有 character framing 画一张定妆图，图片记入条目的 `images`。这些图计入本次图片数。
- 之后的页：新出现的人物只建资料条目，不自动画图；该页下方提示“新角色：林夏 · 画定妆图”，点一下画一张。
- 每页的参考图 = 出场人物的定妆图（按出场顺序）+ 上一页图片，按现有参考图上限截断；不支持参考图的连接显示“仅用文字设定”（现有文案）。
- 作者在右栏资料里查看、替换角色图片。替换后不自动重画，也不标记任何关卡。
- 每格“参考图（n）”按钮去掉；分镜面板底部有折叠的“本页参考图”，可手动增删，覆盖自动选择。

## 原创漫画的关卡调整

| 情况 | 现在 | 改为 |
| --- | --- | --- |
| 模型检查两轮后仍有问题 | 不画，显示“待检查”，要手动点检查 | 照常画。问题沿用现有的整话检查记录，只显示在本次新画的那一页（“AI 提示 n”，在分镜面板展开）。下一次画页或编辑分镜后，由新的结果取代，不新增每页字段。重画不重新检查 |
| 衔接待复核（`visualReview`） | 阻止继续、方向和导出 | 新原创页不再写入 true；原创文档读取时忽略；恢复历史不再标记 |
| 此前漫画变化（`sourceCurrent` 为假） | 阻止继续 | 不阻止，下次画时按当时的内容取前情 |
| 改了分镜没重画（指纹不符） | 阻止继续 | 页上标“分镜已改，图未更新 · 重画”，不阻止继续；导出时列为提醒 |
| 最后一页没有图 | 阻止，提示不明 | 仍阻止。该页原地显示原因、“重试”“删除此页”；输入区换成“第 n 页处理好后可以继续画” |
| 本话有任务在跑 | 阻止 | 仍阻止，防止重复付费 |

对应的核心改动，仅对原创文档生效：

- `ComicService._originalInput` 只要求此前每页都有图，不再要求 `checked`、`complete`、`sourceCurrent`。
- `generateImages` 不再要求 `checked`。
- 运行器的 compose 在自动修订一轮后无论检查结果都继续绘制。
- 三个方向在最后一页有图时就可以生成；仍是每个漫画版本自动生成一次，失败不自动重试。
- 漫画导出只要求每页有图，指纹不符作为提醒列出。
- 新增“删除此页”：去掉该页和它的格，生成新版本。删除后弹出带“撤销”的提示；撤销用现有恢复操作回到删除前的版本，只在之后没有新改动时可用。

小说改编文档的规则保持原样。

## 界面

### 宽屏（≥ 900）

- **左栏目录**：标题“漫画目录”。每话一行：话标题，副标题“n 页”或“绘制中”。
- **中间漫画画布**（新组件，取代漫画作品的 `ReaderScreen`）：话标题，下面是纵向排列的页，最大宽 760，页间 24。每页下方一行小字“第 n 页”与状态标记。悬停、键盘聚焦或点按时显示页工具条。点页选中，右栏分镜跟着切换。非最后一话的末尾是“下一话”按钮；最后一话的末尾是“接下来”区。
- **右栏工具**：助手、资料、插图、分镜。漫画作品把“漫画”工具改名为“分镜”，显示画布中选中的页，默认最后一页。分镜面板包含：
  - 页号与“AI 提示 n”（展开为问题列表）；
  - 每格一张卡片：画面描述，台词行（类型、说话人、文字），上移、下移、删除；底部“添加一格”；
  - 折叠的“本页参考图”；
  - 底部固定两个按钮：主按钮“保存并重画本页（1 张图）”，次按钮“只保存”。
- **顶栏**：阅读（全屏漫画阅读）、作品操作菜单中新增“导出漫画”。

### 窄屏

- 底栏：目录、漫画、资料、助手、插图。漫画作品默认进入“漫画”（画布）。
- 点页弹出动作菜单：重画此页、改分镜（全屏打开分镜面板）、删除此页。
- “接下来”区与宽屏相同，在最后一页下方。

### 统一的状态写法

| 状态 | 显示 |
| --- | --- |
| 绘制中 | 在那一页的位置：步骤列表、当前步骤进度、“离开也会继续”、取消 |
| 失败 | 一句原因（缺连接、需要 NSFW 生图连接、超时等用作者能懂的话；其余显示任务错误）+ 重试 + 删除此页 + “查看详情”进入任务页 |
| 分镜已改 | 页下方“分镜已改，图未更新 · 重画” |
| 有 AI 提示 | 页下方“AI 提示 n”，点开右栏分镜 |
| 缺连接 | 开篇区或“接下来”区内“还没有生图模型 · 去设置” |
| 本话正在画 | 分镜面板只读，显示“正在画第 n 页，画完后可以编辑”；页工具条的重画、删除不可用；阅读不受影响 |
| 结果未写入 | 画的过程中本话被助手或另一台设备改过：在那一页的位置显示“第 n 页已画好，但期间本话有改动，没有写入 · 比较 / 采用 / 放弃”，复用现有的候选比较 |

不再显示“漫画任务 · 已完成”卡片；任务页仍可从“查看详情”和顶栏任务按钮进入。

### 原来的按钮去哪了

| 原按钮 | 现在 |
| --- | --- |
| 检查连续性 | 去掉，开画前自动检查 |
| 生成漫画 | 去掉，开始画 / 画下一页 / 重画已包含 |
| 确认画面衔接 | 去掉 |
| 编辑分镜（折叠区） | 点页 → 右栏分镜 |
| 参考图（每格） | 自动；手动在分镜面板底部 |
| 重画此页、生图记录 | 页工具条“重画”；“⋯”里有生图记录 |
| 历史版本 | 话标题旁菜单 / 目录每话菜单 → 本话历史版本（仍按整话恢复，与现在相同） |
| 漫画 HTML ZIP | 作品操作菜单 / 每话菜单 → 导出漫画 |
| 刷新三个方向 | “接下来”区右上角“换一批” |

### 作品类型与每话内容

作品类型在作品信息里仍可修改，不锁定，也不改动已有内容。所以漫画作品可能有带小说正文的话或改编漫画，小说作品也可能有原创漫画。中间区域的显示规则：

- **漫画作品**：中间始终是画布，每一话按它的内容显示。
  - 有漫画：显示漫画，原创和改编都显示；新的整页格式和旧的单格格式（`ComicPanelView`）都支持。
  - 没有漫画但有正文：显示卡片“本话有小说正文，还没有漫画 · 阅读正文 · 改编为漫画”。
  - 两者都没有：显示开篇区。
  - 只有原创漫画才在最后一话末尾显示“接下来”区。改编漫画的右栏“分镜”显示改编面板（见下节）。
- **小说作品**：中间仍是小说阅读器。有漫画的章节（原创或改编）显示“看漫画版”。

## 小说作品

- 中间仍是小说阅读器。漫画是本章的另一种呈现，不混入小说正文；要在正文里放单张图，继续用插图功能。
- 阅读器里，本章有漫画时在章节标题处显示“看漫画版”，打开漫画阅读。
- 右栏“漫画”面板保留改编流程，换成同样的写法：顶部三步“编排分镜 → 检查改编 → 绘制”，只有当前步骤有一个主按钮；问题列表就地显示；历史、导出进菜单。忠实检查仍阻止未通过的绘制。

## 不做

自由排版与拖拽气泡；在已有页之间插入新页；目录缩略图；一次生成多页；替换角色图后自动重画；新角色每页自动画定妆图。

## 数据与兼容

- 不改数据库 schema 和备份格式。`visualReview` 字段照常读取，旧小说改编数据行为不变。
- 原创规划输出新增的人物字段只用于本次任务的参考图规划，要不要存进漫画文档由实现者按校验需要决定；存进文档时沿用严格字段校验，旧文档缺这个字段时视为空。
- 角色定妆图是普通资料图片，走现有资源、备份和分支规则。

## 验收

测试使用本地协议服务器与固定图片，不调用付费模型。

1. 空原创作品：开篇区输入一句话，点“开始画”，中间出现第 1 页；全程没有“检查”“确认”步骤。
2. 模型检查两轮仍有问题：照样画出；页上有“AI 提示”；“画下一页”可用。
3. 恢复历史版本、替换角色图之后，可以直接画下一页，不出现“衔接待复核”。
4. 第 3 页绘制失败：只能在第 3 页原地重试或删除；删除后可以继续画。
5. 改分镜后“只保存”：页上标“图未更新”，继续画可用；“保存并重画本页”只产生一次生图请求。
6. 开篇开启定妆：最多为 3 个主要角色建资料与定妆图，第 1 页请求带这些参考图（受连接上限）；第 2 页起复用，不再重复画；关闭开关时不画定妆图。
7. 点方向卡片只填入输入框，不发起请求；重复点“画下一页”只产生一个任务。
8. 宽屏中间是画布，右栏分镜随选中页切换；窄屏底栏进入画布，点页弹出动作菜单；页工具条可用键盘到达。
9. 小说作品：有漫画的章节在阅读器显示“看漫画版”；改编的忠实检查仍阻止未通过的绘制。
10. 容器 16 像素内边距、长台词换行、缺连接引导有界面测试覆盖；按项目要求跑 analyze、相关测试与格式检查。真实模型成图效果和原生交互单独标明未验证。

## 设计者的决定（供核对）

1. 漫画作品的中间区域改为漫画画布，小说作品不变。
2. 原创漫画去掉检查、衔接、依据过期三个关卡，只保留“有任务在跑”和“最后一页没图”。
3. 点方向只填入输入框，由作者确认后再画。
4. 开篇默认画最多 3 张角色定妆图，可关；之后的新角色只提示，不自动画。
5. 小说作品里漫画不混入正文，只加“看漫画版”入口。
6. 不支持在已有页之间插入新页。
7. 作品类型不锁定；漫画作品的画布按每话内容显示，正文用卡片入口阅读。
8. 某一话正在画时，这一话的分镜只读；没写入的结果在原位提示，比较后可以采用。
9. 历史版本仍按整话恢复，入口移到话的菜单；删除页后提供“撤销”。
10. AI 提示只显示在最新画的那一页，之后被新的检查结果取代。
