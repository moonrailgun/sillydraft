# 章节编号与章节名分开管理

## 目标

章节标题拆成两部分：“第几章”由应用按目录顺序自动编号，章节名单独存。显示时拼成“第六章 反客为主的午休天台”。起名、改名只动名字，插入、删除、调整顺序后编号自动重排，不再出现有的章节只有编号、有的编号乱序。

本次不做：卷的层级（“第一卷”下重新从第一章数）、手动指定某章的编号、按卷重新编号。

## 现状

- `branch_chapters.title` 存整串标题，如“第六章 反客为主的午休天台”。
- 多处用正则从标题里拆“第几章”：
  - `next_chapter.dart` 的 `nextChapterTitle`：续写下一章时，按上一章的编号加一，并沿用其中文或阿拉伯数字写法；
  - `writing_service.dart` 的 `nameChapter`：只对“只有编号”的标题起名，结果拼成 `'$标题 $名字'`；
  - `_chapterName`：去掉模型回复里的“第几章”。
- 新增章节对话框预填“第N章”。角色卡开局写“第一章”。文本导入缺标题时补“第N章”，有卷名时写成“卷名 · 标题”。
- 阅读器、目录、导出（TXT / Markdown / EPUB）、编辑助手的提示词和工具都直接读 `Chapter.title`。
- 项目备份按表导出行数据，导入时严格校验列（`schema` 为 6 或 8）。

## 数据

- `branch_chapters.title` 改为只存章节名，可以为空。
- `branch_chapters` 新增 `numbered INTEGER NOT NULL DEFAULT 1 CHECK(numbered IN (0, 1))`：是否计入编号。
- `novels` 新增 `chapter_numerals TEXT NOT NULL DEFAULT 'chinese' CHECK(chapter_numerals IN ('chinese', 'arabic'))`：数字写法。
- 编号不存。某章的编号等于本分支中排在它之前（含它自己）、计入编号的章节数。不计入编号的章节没有编号。

`Chapter` 模型：

```
Chapter {
  name: String,     // 存储的章节名，可为空
  number: int?,     // 自动编号；不计入编号时为 null
  title: String,    // 显示标题，见下
  ...其余字段不变
}
```

显示标题（核心包唯一入口，例如 `chapterTitle(number, name, numerals)`）：

| 计入编号 | 名字 | 显示 |
|---|---|---|
| 是 | 反客为主的午休天台 | 第六章 反客为主的午休天台（阿拉伯写法：第6章 反客为主的午休天台） |
| 是 | 空 | 第一章 |
| 否 | 序章 | 序章 |
| 否 | 空 | 空（界面照旧显示“未命名章节”） |

`title` 仍是显示标题，所以阅读器、目录、导出、提示词等读取方不用改。中文数字的生成与解析（`chineseNumber`、`_chapterNumber`）从 `lib/features/reader/next_chapter.dart` 移到核心包。

## 拆分规则

**解析**：核心包函数 `splitChapterTitle(String title)`。标题以“第N章”开头时（N 为阿拉伯数字、全角数字或中文数字，“第”“章”两侧可有空格），解析出 N、N 的写法，以及名字（其后的部分，去掉开头的空格和 `：: · - —` 等分隔符）。其他标题解析不出 N，名字为整个标题（去掉首尾空白）。

例：“第六章 反客为主的午休天台”→ 6，名字“反客为主的午休天台”；“第12章：夜雨”→ 12，阿拉伯，名字“夜雨”；“序章”“卷一 · 第三章 归途”→ 无编号，原样作为名字。

**已有标题（迁移、导入）**：核心包函数 `numberChapterTitles(List<String> titles)`，按目录顺序逐章处理，保证显示不变：

- 解析出的 N 等于这一章按自动编号会得到的号（此前已计入编号的章数加一）：计入编号，名字为解析出的名字；
- 否则：不计入编号，整个原标题作为名字。

例：“第一章 码头、第二章 灯塔”→ 都计入编号；“序章、第一章 码头”→ 序章不计入，第一章计入；“第一卷 起雾 · 第一章 码头、第二章 灯塔”→ 第一章带卷名前缀解析不出编号，第二章的 2 对不上自动编号 1，两章都原样保留，显示不变。跳号的作品，从跳号处起原样保留。

**新建章节**：以整串标题新建时（`createChapter(title: …)`），解析出 N 的就计入编号（N 本身不用，编号由顺序决定），名字为解析出的名字；解析不出的不计入编号，原样作为名字。

**切换为计入编号**：名字以“第N章”开头时去掉这部分，避免显示成“第二章 第三章 归途”。

## 迁移

不在代码中保留迁移：开发者本地的作品库一次性手工迁移（按 `numberChapterTitles` 拆分标题、推断写法，版本号设为 9）。更早版本的作品库和备份不再支持，旧版升级步骤与旧备份转换随之删除：打开旧作品库报“不再支持的旧版本”，导入 schema 9 以外的备份报“不支持的项目备份格式”，数据都不改动。

## 行为

- **新增章节**：对话框只问章节名，可留空，默认空；新章计入编号。
- **改名**：只改名字，预填当前名字；允许改成空。
- **是否计入编号**：章节菜单加“不计入编号 / 计入编号”切换，切换后其后各章编号随之变化。切换为计入编号时，名字开头的“第N章”被去掉。
- **从此章起全部计入编号**：这一章及其后名字仍以“第N章”开头、不计入编号的章节一并计入，名字去掉“第N章”；番外等不受影响。只在这一章或其后有这类章节时出现在章节菜单里。
- **数字写法**：作品设置（`novel_dialog.dart`）加“章节编号：中文数字 / 阿拉伯数字”。
- **调整顺序、删除章节**：编号自动重排，不需要额外处理。
- **分叉分支**：复制 `branch_chapters` 时带上 `numbered`。
- **续写下一章 / 故事走向**：去掉 `nextChapterTitle`。新章计入编号，名字为所选走向的名字。复用末尾空章节时只改它的名字。
- **AI 起名**（`nameChapter`）：条件改为“计入编号且名字为空且有正文”；只写入名字；“期间被改名”判断改为比较名字。`_chapterName` 仍去掉模型回复里的“第几章”。
- **其他新建入口**：
  - 角色卡开局：名字为空，计入编号，显示“第一章”；
  - 文本、EPUB、Markdown 导入：各章标题经 `numberChapterTitles` 处理；缺标题时不再补“第N章”，改为名字为空、计入编号；作品写法按导入的标题推断；
  - 故事开局候选、酒馆助手接口、示例作品：标题经拆分规则处理。
- **导出与提示词**：继续用显示标题。

## 测试

核心包（`dart test`）：

- 解析：中文、阿拉伯与全角数字，空格，分隔符，无编号标题，卷名前缀；
- `numberChapterTitles`：连续编号、序章、卷名前缀、跳号；
- 编号计算：不计入编号的章节不占号；调整顺序与删除后重排；`getStory` 与 `getChapter` 编号一致；
- 显示标题：上表四种情况与两种写法；
- 旧版本作品库被拒绝打开且不被改动；
- 导入：拆分与写法推断；
- AI 起名：只在计入编号且名字为空时起名，只写名字。

界面（`flutter test`）：

- 新增章节：只填名字，显示为“第N章 名字”；
- 改名：只改名字，编号不变；
- 切换“不计入编号”后，目录中后续章节编号变化；
- 作品设置切换数字写法后，目录显示随之变化。

文档：`docs/user-guide.md` 写明章节编号自动生成、名字单独修改、“不计入编号”和数字写法。
